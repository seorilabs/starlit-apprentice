# ADR-0001 docs/ 를 실행 원장으로 삼는다

- 상태: `accepted`
- 날짜: 2026-08-23

## 맥락
이전 구조는 `docs/` 25개 평면 파일과 `qa/` 생성물이 뒤섞여 있었고, `check-release.mjs`의 1,155줄이 그 산문에 특정 문자열이 있는지 `String.includes`로 검사했다. 문서가 검증 대상이 아니라 검증 회피 수단이 돼 있었다.

## 결정
`docs/`를 9폴더 원장 + `game-design/` 설계 팩으로 재구성한다. 문서 검증은 **구조만** 본다(폴더 존재, README 존재, ADR 번호 연속성). 산문 내용은 검사하지 않는다.

## 근거
저자가 쓴 문장에 저자가 고른 문구가 있는지 확인하는 것은 아무것도 검증하지 않는다. `README.md`가 80줄짜리 pnpm 명령 덤프였던 것도 그 체크가 강제한 결과였다.

## 결과
문서 품질은 사람이 판단한다. CI는 구조만 보장한다.
