# ADR-0006 Web pck 예산을 gzip 6MB 로 고정한다

- 상태: `accepted`
- 날짜: 2026-08-23

## 맥락
AppsInToss는 **"미니앱이 10초 이내에 최초 화면까지 정상적으로 열려요"**를 요구한다. 출시된 org Godot 게임을 실측했다.

| 산출물 | raw | gzip |
|---|---:|---:|
| Godot 엔진 wasm | 35.9~37.6 MB | **8.9~9.6 MB** |
| lizard-tycoon pck | 5.7 MB | 3.8 MB |
| spiritgate pck | 44.4 MB | **42.4 MB** |

Godot 공식 문서도 `.wasm`이 gzip으로 약 1/4까지 줄어든다고 명시하며 실측과 일치한다.

## 결정
- 엔진 wasm 약 9 MB는 고정 바닥값으로 받아들인다.
- **pck 상한을 gzip 6 MB로 고정**하고 아트 에셋 매니페스트(152종)를 여기 종속시킨다.
- 총 전송량 목표 ≤ 15 MB gzip.

## 근거
lizard-tycoon이 총 gzip 약 12.7 MB로 이미 AppsInToss에 출시돼 있다 — 존재 증명이다. 반면 spiritgate의 pck는 텍스처가 이미 압축돼 gzip이 거의 듣지 않는다(44.4→42.4 MB). **로드 시간을 죽이는 것은 코드가 아니라 텍스처다.**

## 결과
- 엔딩 일러스트 30종을 전부 대형 원본으로 넣을 수 없다. 공통 프레임 + 중앙 일러스트로 분해한다.
- VRAM 텍스처 압축은 네이티브에 유리하지만 Web pck에서는 gzip 효율을 떨어뜨린다. Web preset의 텍스처 처리를 네이티브와 분리해 결정하고 조합별 pck 크기를 실측해 고른다.
- **P3 완료 직후, 콘텐츠를 채우기 전에** 실기기에서 최초 화면 도달 시간을 선측정한다.
