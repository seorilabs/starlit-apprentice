## 타깃과 플랫폼

- **1차 타깃**: 한국어권 모바일 캐주얼 플레이어. 15~20분 단위로 한 회차를 끝내고 결과를 확인하고 싶은 사람.
- **플레이 상황**: 출퇴근, 자기 전, 짧은 대기 시간. 세로 한 손 조작.
- **인접 대체재**: 수험생 키우기 같은 현실 소재 육성 시뮬, 짧은 선택형 서사 게임, AppsInToss 캐주얼 게임군.

## 플레이어 판타지와 제품 기둥

**판타지**: "내가 고른 한 주 한 주가 쌓여, 이 아이가 어떤 어른이 되는지 지켜본다."

| 기둥 | 내용 | 이것이 깨지면 |
|---|---|---|
| P1 **선택이 남는다** | 매주 고른 것이 스탯·관계·서사에 즉시 보이고, 마지막 엔딩까지 이어진다 | 대시보드에 숫자만 오르는 스프레드시트가 된다 |
| P2 **사람이 있다** | 스승·라이벌·동료가 기억되고, 관계가 진로를 연다 | 파라미터만 남고 육성 시뮬의 온기가 사라진다 |
| P3 **잘못될 수 있다** | 무리하면 슬럼프·부상·번아웃·낙제가 실제로 온다 | 무위험 우상향이 되어 결정이 무의미해진다 |
| P4 **다시 할 이유가 있다** | 재능·이벤트 덱·진로·각인·선배가 회차마다 달라진다 | 같은 게임을 30번 반복하게 된다 |

## 경험 타임라인

| 구간 | 플레이어가 얻는 것 |
|---|---|
| **10초** | 별빛 아카데미의 밤하늘과 견습생이 보이고, 첫 행동 카드 4장 중 하나를 고른다 |
| **3분** | 3~4주를 진행해 스탯이 오르고 첫 이벤트 선택지를 만난다. 세라(스승)를 알게 된다 |
| **30분** | 1~2회차를 끝내고 엔딩 1~2개를 도감에 넣는다. 별조각으로 첫 각인을 산다 |
| **7일** | 도감 8~12종, 진로 선택지 확장, NPC 2~3명과 신뢰 이상, 선배 명부 축적 |

## 범위

**포함**
- 12개월 × 3턴 = 36턴 주 단위 육성 루프
- 스탯 9종 + 평판, 체감 감소 성장 곡선, 분기 상한
- 상태이상 6종 (부진·슬럼프·부상·번아웃·평판 추락·낙제)
- 선택지 있는 이벤트 106종 / 선택지 286개
- NPC 6명, 호감 5단계, NPC 전용 엔딩 6종
- 엔딩 30종 (실패 3 / 일상 5 / 전문 10 / 희귀 8 / 전설 4), 특이도 점수 판정
- 메타 진행: 도감 진로 해금, 별조각·각인 6종, 선배 명부
- 플랫 일러스트 아트, BGM 3 + 스팅어 + SFX
- 로컬 저장 1슬롯 + 도감, GA4 분석, 광고(Android/iOS)

**제외 (근거 명시)**
| 제외 | 이유 |
|---|---|
| 로그인·서버 세이브 | 로컬 완결 게임이라 불필요. 계정 이전 요구가 확인되면 재검토 |
| 인앱 결제 | v1은 광고만. 광고 제거 IAP는 지표 확인 후 |
| 영어 등 다국어 | 한국어 전용 출시. 문자열은 전부 분리해 두어 추가 비용을 텍스트로만 남김 |
| 프레임 애니메이션 스프라이트시트 | 에셋 파이프라인 범위 밖. Godot tween·셰이더·파티클로 대체 |
| AppsInToss 광고 | 정책상 허용되나 Godot Web에 네이티브 광고 경로가 없다. 후속 과제 |

## 제작 제약과 팀

- 1인 + AI 에이전트. 아트·사운드는 생성 파이프라인 사용.
- **콘텐츠 저작이 최장 경로**: 약 70,300자, 약 28일 (이벤트 42,000자가 60%).
- **번들 예산**: 총 전송량 ≤ 15 MB gzip (엔진 wasm 약 9 MB 고정 + pck ≤ 6 MB). 근거는 [[01-research-dossier]] 부록 A.
- 빌드 경계: Android AAB는 x64 Linux, Apple 아카이브는 macOS 또는 Xcode Cloud.

## 가정과 미결정

| # | 항목 | 상태 | 영향 |
|---|---|---|---|
| A1 | Godot Web이 AIT 10초 제약을 만족한다 | **가정** — lizard-tycoon 12.7MB gzip 선례로 뒷받침되나 본 게임 실측 전 | 틀리면 AIT 타깃 재검토 |
| A2 | 한국어 폰트 페이스 | **미정** | Pretendard Variable 또는 NotoSansKR 권장. 라이선스를 third-party notices에 기재 |
| A3 | iOS 전달 경로 | **미정** | GitHub `macos-26` vs Xcode Cloud. 첫 제출 시점에 결정 |
| A4 | 개인정보처리방침 URL | **미정** | per-app 페이지 권장(`seorilabs-official` 신설 필요) |
| A5 | ASC 담당자 실명·전화 | **미정** | 실존 인물 정보라 추정 불가 |
| A6 | 재능·각인 랜덤이 확률형 아이템 공시 대상인지 | **미정** | 유료 구매와 무관한 게임 내 랜덤이라 대상 아님으로 보되, 등급 신청 전 확인 |

## 성공과 중단 기준

**출시 게이트 (전부 충족해야 출시)**
- 밸런스 불변식 1~17 통과
- 실기기에서 AIT 최초 화면 도달 10초 이내
- 3마켓 서명 산출물 + 미확정 스토어 필드 0건
- IARC 등급 취득 → AIT 자체등급분류 정보 입력 완료

**출시 후 유지 판단 (D+28)**
| 지표 | 유지 | 재검토 |
|---|---|---|
| D1 잔존율 | ≥ 25% | < 15% |
| 1회차 완주율 | ≥ 40% | < 20% |
| 중앙값 세션 길이 | 12~25분 | < 6분 |
| 2회차 진입률 | ≥ 30% | < 12% |

> GA4가 Measurement Protocol Web 스트림이라 `newUsers`·잔존율이 구조적으로 0이다. 위 지표는 자체 `first_launch` 이벤트와 BigQuery 재구성으로 산출한다. 근거는 계획 B6.
