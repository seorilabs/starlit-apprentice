- 문서 상태: `draft`

## 아트 방향

**픽셀 아트에서 굵은 아웃라인 플랫 일러스트(동화책 톤)로 전환한다.**

전환 근거:
- 현행의 "픽셀 아트"는 타이틀 화면 문구일 뿐 실체가 없다. 씬 전체가 `fillRect` 98회이고 캐릭터는 사각형 13개다. **보존할 픽셀 자산이 없으므로 잃는 것도 없다.**
- 에셋 생성 파이프라인은 스프라이트시트·프레임 애니메이션을 **명시적으로 범위 밖**에 둔다. 진짜 픽셀 아트는 손으로 그린 프레임 작업을 요구한다.
- 파이프라인이 가장 안정적으로 만드는 스타일 계열이 **굵은 아웃라인 플랫 벡터**이고, 축소 시에도 잘 읽힌다.
- 경쟁작이 전부 현실 소재(수능·편의점·경마)라 **별빛 아카데미 판타지의 동화책 룩은 이 시장에서 비어 있는 톤**이다([[01-research-dossier]] O4).

**무드 어휘**: 고요한 · 밤의 · 따뜻한 · 별빛 · 잉크와 양피지 · 조용한 성장.

## 시각 문법

**스타일 가이드 (프롬프트에 그대로 넣을 한 문단)**

> Flat vector illustration with thick uniform dark outlines, storybook picture-book look. Soft flat shading with at most two tones per surface, no gradients, no texture noise. Palette limited to `#161B2D` night navy, `#1E2540` deep panel blue, `#F4F1E8` warm parchment, `#F2C75C` starlight gold, `#3E8E8A` muted teal, `#D97A7A` dusty rose. Light source is a single warm lantern or starlight from the upper left. Rounded, friendly proportions. Centered single subject, isolated on a flat removable pure white background, no ground shadow, no text.

| 규칙 | 값 |
|---|---|
| 아웃라인 | `#0E1120`, 균일 굵기, 720 기준 3~4px |
| 음영 | 면당 최대 2톤. 그라디언트 금지 |
| 팔레트 | 위 6색 + 피부/머리 보조 2색까지만 |
| 광원 | 좌상단 단일 (등불 또는 별빛) |
| 실루엣 | 축소 시 형태만으로 식별 가능해야 한다 |
| 텍스트 | **에셋에 글자를 굽지 않는다.** 특히 한글 |

## 캐릭터와 세계

**견습생** — 주인공. 중성적 실루엣, 별 자수가 있는 로브. **성장 3단계**(1·2·3분기 경계에서 교체)와 **표정 6종**(호조·보통·부진·슬럼프·번아웃·각성)을 정적 포즈로 만든다. 이중 레퍼런싱(스타일 앵커 + 견습생 원본)으로 동일성을 유지한다.

**NPC 6명** — 각 1개 기본 초상 + 2개 표정 변형.

| 인물 | 시각 키 |
|---|---|
| 세라 (스승) | 은발, 짙은 남색 로브, 손에 관측표 |
| 이든 (라이벌) | 붉은 머리끈, 짧은 망토, 팔짱 |
| 하린 (동기) | 둥근 안경, 앞치마, 주판 |
| 모란 (후원자) | 금실 자수 숄, 부채 |
| 구 노인 (장인) | 흰 수염, 가죽 앞치마, 그을린 손 |
| 윤 (떠돌이) | 넓은 챙 모자, 낡은 배낭 |

**세계** — 별빛 아카데미. 배경 8종: 견습생 방, 도서관, 천문탑, 공방, 극장, 광장, 정원, 밤시장. 계절 색조 4종을 셰이더로 덧입혀 32조합을 8장으로 커버한다.

## UI 아트 경계

**엔진 우선.** 구조는 Godot `Theme`/`StyleBoxFlat`로 만들고, 생성 이미지는 장식에만 쓴다.

| 엔진에서 만든다 | 생성 이미지를 쓴다 |
|---|---|
| 버튼·패널·카드 프레임(늘어나야 함) | 행동 아이콘 38종 |
| 모든 텍스트 | 이벤트 일러스트 |
| 진행 바·별자리 레이더 | 엔딩 일러스트 |
| 상태 색·대비 | 자원 토큰 3종, 각인 아이콘 6종 |

늘어나는 버튼·패널 PNG를 통째로 생성하지 않는다. 장식 프레임이 필요하면 `NinePatchRect`용으로 테두리를 균일하게 생성한다.

## 에셋 매니페스트

`assets/art/asset-manifest.json`으로 관리한다. 경로 규약: `assets/art/style/{style-guide.md,anchor.png}`, `assets/art/<name>.png`, `assets/art/raw/<name>.png`.

| 그룹 | 수량 | 크기 | 투명 |
|---|---:|---|---|
| 스타일 앵커 | 1 | 1024 | 아니오 (흰 배경 원본) |
| 견습생 (3단계 × 6표정) | 18 | 512 | 예 |
| NPC (6명 × 3변형) | 18 | 512 | 예 |
| 배경 | 8 | 1536 (9:16) | 아니오 |
| 행동 아이콘 | 38 | 256 | 예 |
| 이벤트 일러스트 | 24 | 768 | 아니오 |
| **엔딩 일러스트** | **30** | **768** | 아니오 |
| 자원 토큰·각인·UI 장식 | 15 | 256 | 예 |
| **합계** | **152** | | |

> **크기 상한은 매니페스트를 더 이상 구속하지 않는다.** 하드 리밋은 AppsInToss 패키징 100 MB 뿐이고, 10초 조항은 커스텀 로딩 셸이 맡는다(ADR-0009). 다만 텍스처는 gzip이 듣지 않으므로 **에셋을 추가할 때마다 `scripts/check_web_budget.sh` 로 실측해 증가분을 기록한다.** Web preset의 텍스처 처리는 네이티브와 분리해 결정한다.

## VFX 언어

전부 Godot 코드로 만든다(tween · 파티클 · 셰이더). **프레임 애니메이션 스프라이트시트는 만들지 않는다.**

| 효과 | 구현 |
|---|---|
| 견습생 대기 | 4~7px 상하 tween, 이징 sine.inout |
| 행동 비트 | 스케일 스쿼시&스트레치 + 소품 회전 |
| 별자리 점 발광 | 셰이더 글로우 + 스케일 펄스 |
| 숫자 팝 | 상승 + 페이드, 성장은 teal, 비용은 rose |
| 대성공 | 화면 가장자리 금색 비네트 플래시 + 파티클 12개 |
| 각성 | 별자리 전체 점멸 + 화면 흔들림 0.3초 |
| 상태이상 | 채도 감소 셰이더 지속 |
| 계절 전환 | 배경 색조 크로스페이드 0.6초 |

`감소된 모션` 설정 시 흔들림·파티클·push-in을 끈다.

## 오디오와 햅틱

### 오디오 용량 예산 (P3 실측으로 확정)

빈 프로젝트 + 폰트만으로 Web export 를 뽑은 결과 **pck gzip 1.45 MB 중 폰트가 1.11 MB(77%)** 였다.
아트 152종 · 오디오 · 콘텐츠 JSON 전부가 남은 **4.55 MB gzip** 을 나눠 쓴다.

| 항목 | 예산 | 근거 |
|---|---:|---|
| BGM 3종 합계 | **≤ 1.6 MB** | 각 ≤ 550 KB. 90초 모노 `.ogg` ~72 kbps 기준 |
| 스팅어 4종 합계 | ≤ 120 KB | 각 ≤ 30 KB, 2~4초 |
| SFX 전체 | ≤ 180 KB | Kenney CC0 / jsfxr, 짧고 모노 |
| **오디오 소계** | **≤ 1.9 MB** | 남은 여유의 42% |
| 아트 152종 + 콘텐츠 | ≤ 2.65 MB | 나머지 |

**BGM 은 모노로 만든다.** 스테레오 90초 `.ogg` 는 1 MB 를 넘겨 3종이면 예산을 초과한다.
`.mp3` 를 쓰지 않는다 — 인코더 지연이 루프 시작에 공백을 만든다.
생성 후 `bash scripts/check_web_budget.sh .` 로 실측하고, 초과하면 길이를 먼저 줄인다.

**BGM 3종 (seamless loop, `.ogg`, 모노)**

| 이름 | 길이 | 프롬프트 방향 |
|---|---:|---|
| `bgm_main` | 90초 (≤550 KB) | 고요하고 따뜻한 육성 시뮬 배경음, 하프와 첼레스타, 부드러운 현 패드, 잔잔한 별빛 무드 |
| `bgm_event` | 60초 (≤400 KB) | 이벤트 장면용, 목관과 피치카토 현, 호기심 어린 중간 템포 |
| `bgm_milestone` | 60초 (≤400 KB) | 시험 장면용, 낮은 현과 팀파니, 긴장되지만 과하지 않은 |

**스팅어 4종 (oneshot, `.wav`)**: `sting_success`, `sting_fail`, `sting_awaken`, `sting_ending`.

**SFX** — 일반 효과음(탭·확정·페이지·코인)은 **Kenney CC0 또는 jsfxr 절차 생성**을 우선한다. 생성 API는 대체 불가한 특수음에만 쓴다.

**햅틱**: 탭 light / 확정 medium / 대성공 medium / 각성 heavy / 실패 medium / 상태이상 heavy.

**AppsInToss 요구사항**(SRC-001): 사운드 On/Off 사용자 설정 **필수**. 백그라운드 전환 시 **즉시 종료**, 복귀 시 정상 재생. 광고 재생 중 음악 일시정지, 종료 후 재개. BGM은 `.ogg`로 내보내고 mp3를 쓰지 않는다(인코더 지연이 루프 시작에 공백을 만든다).

## 생성과 라이선스

| 항목 | 값 |
|---|---|
| 이미지 | `game-asset-pipeline` (스타일 앵커 + 배치 생성 + 투명 후처리 + 콘택트시트 QA) |
| 오디오 | `game-sound-pipeline` (BGM 루프 + 스팅어), SFX는 Kenney CC0 / jsfxr |
| 폰트 | **Pretendard 1.3.9 정적 Regular** (SIL OFL 1.1). 볼드는 `FontVariation` 합성. P7 에서 사용 글리프로 서브셋. 근거는 `docs/02-decisions/0007-font-budget.md` |
| 추적 | 에셋마다 출처·모델·프롬프트/레퍼런스·라이선스·수정 이력·마켓 사용 가능 여부를 매니페스트에 남긴다 |

원본 생성물(`raw/`)은 저장소에 유지한다. 재처리는 무료지만 재생성은 비용이 든다.

## 승인 게이트

> **아트 방향과 스타일 앵커는 취향 결정이므로 에이전트가 스스로 `approved`로 표시하지 않는다.**

| 게이트 | 산출물 | 승인자 | 상태 |
|---|---|---|---|
| G1 | 스타일 가이드 문단 | 사용자 | **대기** |
| G2 | 스타일 앵커 1장 (흰 배경) | 사용자 | G1 이후 |
| G3 | 견습생 기본 + 세라 초상 | 사용자 | G2 이후 |
| G4 | 대표 플레이 화면 고해상도 목업 | 사용자 | G3 이후 |
| G5 | 배치 152종 콘택트시트 QA | 에이전트 검수 후 사용자 확인 | G4 이후 |
| G6 | BGM 3종 청취 QA | **사용자 청취 필수** | G5와 병렬 |

**G2 이전에 배치 생성을 실행하지 않는다.** 앵커가 바뀌면 전체를 다시 만들어야 한다.
