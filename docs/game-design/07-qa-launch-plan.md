## 기기와 플랫폼 매트릭스

| 구분 | 기기 | 확인 목적 |
|---|---|---|
| Android 저사양 | RAM 3~4GB, Android 10 | 프레임·발열·콜드 스타트 |
| Android 대표 | RAM 8GB, Android 14~15 | 기준 동작 |
| iOS 저사양 | iPhone SE 3세대급 | 좁은 화면·성능 |
| iOS 대표 | iPhone 15~16급 | 기준 동작 |
| **AIT Android** | Toss 앱 QR 샌드박스 | **10초 제약 · 한국어 렌더 · Safe Area** |
| **AIT iOS** | Toss 앱 QR 샌드박스 | **WebKit 렌더 (R17) — Android 통과가 iOS 통과를 의미하지 않는다** |
| 태블릿 | Android 태블릿 1종, iPad 1종 | 세로 고정·레터박스 |

**AIT는 Android와 iOS를 별도 인수 항목으로 분리한다.** Godot 공식 문서가 Safari WebGL 2.0 문제를 명시한다([[01-research-dossier]] 부록 B).

## 개인정보 정책과 연령등급

**분석과 광고를 넣으면 개인정보 표기가 "수집 안 함"에서 "수집함"으로 바뀐다.** 세 마켓의 공시를 동시에 갱신해야 한다.

| 항목 | 내용 | 상태 |
|---|---|---|
| 수집 데이터 | 익명 식별자, 게임 진행 파라미터, 광고 식별자(Android/iOS) | 확정 |
| 개인정보처리방침 URL | per-app 페이지 (`seorilabs-official` 신설 필요) | **미정** |
| Play 데이터 안전 | 수집 항목·목적·전송·삭제 요청 경로 | 미작성 |
| App Privacy (ASC) | Data Collected / Not Linked / No Tracking | 미작성 |
| `PrivacyInfo.xcprivacy` | 필수 사유 API 선언 | 미작성 |
| Android `AD_ID` 권한 | 광고 SDK가 병합. 데이터 안전과 일치해야 함 | 미작성 |
| **IARC 연령등급** | Play·ASC 설문 → 전체이용가 목표 | **미취득** |
| **자체등급분류 정보 (AIT)** | **IARC 취득 후** AIT 콘솔 입력 | **미입력** |

> **미입력 시 등급미필 게임물로 간주되어 시정권고·수사의뢰·행정처분의뢰로 이어질 수 있다**([[01-research-dossier]] SRC-003).

**등급 경로 (확정)**
```
Play / App Store IARC 설문 → 연령등급 취득
        ↓
AppsInToss 콘솔에 자체등급분류 게임물 정보 입력
        ↓
AppsInToss 출시
```
직접 GRAC 신청 경로도 있으며 심의에 약 10~15일이 걸린다(SRC-002). 대안 경로로만 둔다.

## 스토어와 정책

**현행 스토어 메타데이터는 전면 재작성 대상이다.** 카피가 "픽셀 육성 시뮬레이션"이고 명시적으로 "광고 SDK가 포함되지 않습니다"라고 적혀 있어 아트 방향·수익화 결정 양쪽과 충돌한다. 스크린샷 20장도 전부 구 DOM 게임 화면이라 무효다.

| 항목 | 상태 |
|---|---|
| 앱 이름·설명 (3마켓) | 재작성 필요 |
| 스크린샷 (Play 폰·태블릿, ASC 6.9"·iPad, AIT 636×1048) | **전면 재생성** |
| 아이콘·피처 그래픽 | 신규 아트로 재생성 |
| AIT 로고 600×600 + 썸네일 1932×828 | 재생성 + **콘솔 등록 필수** (`granite.config.ts` 차단) |
| `sku`, `supportUrl`, `marketingUrl` | 채울 수 있음 |
| ASC 담당자 실명·전화 | **미정** — 실존 인물 정보 |
| AIT 게임 카테고리·노출 | 콘솔 |

## 출시 포지셔닝과 획득

- **한 줄 포지셔닝**: "열두 달, 서른여섯 번의 선택으로 견습생의 미래가 갈린다."
- **차별점**: 경쟁작이 전부 현실 소재(수능·편의점·경마)인 시장에서 **별빛 아카데미 판타지 + 동화책 아트**([[01-research-dossier]] O4).
- **첫 스크린샷**이 획득의 전부다. 대시보드가 아니라 장면이 보여야 한다.
- AIT는 미니앱 1만 개 중 게임이 50%라 노출 경쟁이 심하다. **첫 10초가 전부다.**
- 유료 UA 없음. 스토어 자연 유입 + AIT 노출 + 엔딩 공유 링크.

## 현지화와 고객지원

- **v1은 한국어 전용.** 문자열은 `i18n/translations.csv`로 전부 분리해 두어 영어 추가가 텍스트 작업만으로 끝나게 한다.
- 저장 레코드가 렌더된 문자열이 아니라 i18n 키를 담으므로, 나중에 언어를 바꿔도 과거 기록이 살아남는다.
- 지원 채널: `https://www.seorilabs.com/support/` + `cs@seorilabs.com`.
- AIT 웹보드 게임이 아니므로 성인 인증·확률 공시 의무 대상이 아니다. 단 **재능·각인 랜덤이 확률형으로 해석될 여지**는 등급 신청 전에 확인한다.

## 소프트론칭

**형태**: Google Play 내부 테스트 트랙 → 닫힌 테스트.

| 단계 | 규모 | 확인 |
|---|---|---|
| 내부 테스트 | 5~10명 | 크래시, 완주 가능 여부, 명백한 밸런스 붕괴 |
| 닫힌 테스트 | 30~50명 | 세션 길이 분포, 이탈 턴, 2회차 진입률 |

**소프트론칭에서 확인할 가설**: H1(세션 길이), H3(2회차 신규 비율), H5(광고 수용도).

**AIT와 App Store는 소프트론칭을 하지 않는다.** AIT는 단계 배포가 없고, App Store는 TestFlight로 대체한다.

## 롤백과 운영

| 상황 | 대응 |
|---|---|
| 크래시 급증 | Play 단계 배포 중단 → 이전 버전 유지. AIT는 이전 번들 재배포 |
| 광고 문제 | RemoteConfig `ads_enabled=false` 킬 스위치 (앱 배포 불필요) |
| 밸런스 붕괴 | 클라이언트 패치 필요. **밸런스 상수는 원격 설정에 두지 않는다** — 하네스 검증 대상이기 때문 |
| 분석 과다·오류 | RemoteConfig `analytics_enabled=false` |
| 저장 손상 확산 | `min_supported_version` 상향으로 강제 업데이트 |
| 점검 | `maintenance_mode=true` |

**모든 원격 키에 폴백 상수가 있어 원격이 죽어도 게임은 정상 동작한다.**
