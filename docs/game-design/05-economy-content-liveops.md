## 재화 Source와 Sink

**금화** — 유일한 경성 재화. 현행에서 골드는 사실상 제약이 아니었다(무료 휴식 2종 + 하한 0).

| Source | 양 | 빈도 |
|---|---:|---|
| 시작 자금 | 120 | 런 1회 |
| 일: 잡일 | +18 | 무제한 |
| 일: 공방 | +38 | 무제한 |
| 일: 서기관 | +45 | 무제한 |
| 이벤트 보상 | +20 ~ +90 | 런당 3~6회 |
| 마일스톤 급제/장원 | +40 / +80 | 최대 4회 |
| 각인 `곳간의 각인` | +80 | 장착 시 |

| Sink | 양 | 빈도 |
|---|---:|---|
| **월납 수업료** | **−40** | **12회 = −480 (필수)** |
| 수업 기초 | −10 ~ −35 | 선택 |
| 수업 심화 | −45 | 선택 |
| 수업 비전 | −80 | 선택 |
| 외출 | −12 ~ −15 | 선택 |
| 온천 (슬럼프 해제) | −50 | 선택 |
| 치료 (부상 단축) | −80 | 선택 |
| 약 (번아웃 1턴 회수) | −120 | 선택 |

**구속성 증명**: 필수 학비 480 + 심화 12턴 540 = **1,020금화** 대 시작 120. 일 수입 55/턴 기준 **36턴 중 약 17턴을 일에 써야 하고**, 이는 수업 턴과 1:1로 경쟁한다. 불변식 13이 30루트 중 20개 이상에서 금화 40 미만 구간을 요구한다.

**기력 / 마음** — 연성 재화. 저장되지 않고 매 턴 압박한다. 월말 무상 회복은 삭제한다. 휴식 회복량이 `18 + floor(체력/6)`이라 **체력 투자가 경제 투자이기도 하다**.

**평판** — 스탯 배열 밖의 사회 지표. 이벤트·마일스톤·NPC·공개 업무로만 오른다. 단일 행동 반복으로는 오르지 않는다.

**별조각** — 메타 재화. `10 + 3×신규엔딩 + 2×신뢰NPC + 5×무낙제` ≈ 런당 18~35.

## 보상 일정

| 시점 | 보상 |
|---|---|
| 매 턴 | 스탯 획득 + NPC 호감 +2 |
| 3턴 중 1턴 | 기회 이벤트 |
| 호감 밴드 도달 | NPC 이벤트 + 게이트 해금 |
| 월말 | 수업료 청구(음의 보상 — 압박 리듬) |
| 계절 (4회) | 마일스톤 등급 + 금화 + 평판 |
| 월 7 | 진로 선언 + 전용 비전 해금 |
| 런 종료 | 엔딩 + 도감 + 별조각 |

**리듬**: 매 턴 작은 보상 → 3턴마다 서사 → 3개월마다 판정 → 런 끝에 정산. 빈 구간을 만들지 않는다.

## 수익화 카탈로그

**광고만. 인앱 결제 없음.** Android / iOS 한정.

| # | 지면 | 형식 | 한도 | 가치 |
|---|---|---|---|---|
| M1 | 두 번째 별 — 현재 턴 결과 재굴림 | 보상형 | 런당 2회 | 실패 턴 회수 |
| M2 | 런 종료 별조각 +50% | 보상형 | 런당 1회 | 메타 가속 |
| M3 | 이번 런 각인 슬롯 3 → 4 | 보상형 | 런당 1회 | 빌드 확장 |
| M4 | 엔딩 공유 직후 | 전면 | **2런당 1회** | — |

**원칙**: 광고는 진행을 막지 않는다. 기력 게이트도 대기 타이머도 없다. 전부 **선택적 이득**이다([[01-research-dossier]] O6).

**보상 지급 규칙**: 네이티브 콜백은 힌트일 뿐이다. Platform claim이 `server_verified`일 때만 지급한다.

**AppsInToss**: 정책상 광고가 허용되나 Godot Web에 네이티브 경로가 없어 v1에서는 비활성화한다([[01-research-dossier]] D1). AIT 빌드는 `ads_available = false`.

## 라이브옵스 캘린더

**v1은 라이브옵스를 하지 않는다.** 서버 콘텐츠도, 시즌도, 이벤트 스케줄도 없다. 완전 오프라인 완결 게임이다.

출시 후 지표에 따라 검토할 순서:

| 우선 | 항목 | 트리거 |
|---:|---|---|
| 1 | 이벤트 팩 추가 (덱 4번째) | 2회차 진입률 ≥ 30%인데 5회차 이탈이 크면 |
| 2 | 엔딩 추가 (band 3~4) | 도감 완성률 상위 코호트가 존재하면 |
| 3 | 광고 제거 IAP | 광고 노출 대비 이탈이 유의미하면 |
| 4 | 영어 로케일 | 국내 지표가 유지 기준을 넘으면 |

## 시뮬레이션 증거

밸런스 주장은 전부 재현 가능한 시뮬레이션으로 증명한다. 하네스는 `packages/product-core/tests/`에 있고 CI required check로 돈다.

| 주장 | 증명 | 불변식 |
|---|---|---|
| 어떤 스탯도 턴 29 이전에 100에 닿지 않는다 | 최대 집중 루트 턴별 전개표 (`02-gdd.md` 진행) | 6 |
| 엔딩 30종이 전부 도달 가능하다 | 30 루트 × 7 시드 = 210 루트 재생 | 1~5, 7 |
| 어떤 엔딩도 다른 엔딩을 가리지 않는다 | 요건 집합 정적 린트 | 8 |
| 죽은 턴이 없다 | 유의미 변화 턴 비율 ≥ 90% | 9 |
| 자원이 실제로 구속된다 | 30루트 중 ≥20이 금화 <40, ≥15가 기력 <30 경험 | 13 |
| RNG가 리스크다 | 7,560롤에서 중앙값 실패 > 대성공 | 15 |
| 세션이 15~20분이다 | 추정 초 ∈ [840, 1260] | 14 |

**210 루트 × 36턴 = 7,560 턴 해석.** 헤드리스 1초 미만이라 nightly가 아니라 required check로 둔다.

## 원격 설정

Platform RemoteConfig를 통해 읽는다. **모든 키에 폴백 상수를 두고, 원격이 죽어도 게임은 정상 동작한다.**

| 키 | 폴백 | 용도 |
|---|---|---|
| `ads_enabled` | `true` (Android/iOS), `false` (Web) | 킬 스위치 |
| `interstitial_run_interval` | `2` | 전면 광고 빈도 |
| `rewarded_reroll_max` | `2` | M1 한도 |
| `min_supported_version` | `0.0.0` | 강제 업데이트 |
| `maintenance_mode` | `false` | 점검 |
| `analytics_enabled` | `true` | 수집 중단 |

**밸런스 상수는 원격 설정에 두지 않는다.** 밸런스는 하네스가 검증하는 대상이고, 원격으로 바뀌면 검증이 무의미해진다.
