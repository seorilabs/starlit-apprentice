# Privacy And Data Safety Evidence

This document is the repo-local evidence for Google Play Data safety and App Store App Privacy preparation. Console submissions still need to be completed in each store.

## Product Boundary

- `starlit-apprentice` is a bundled Capacitor game, not a remote website wrapper.
- The first release candidate has no login, payment, server save, production ad SDK, analytics SDK, crash reporting SDK, or third-party tracking SDK.
- Local progress and ending collection are stored on-device only through browser `localStorage`.
- Players can clear local progress and ending collection from the title screen through a two-step local data reset confirmation.
- No user data collected or shared by the app code in this MVP boundary.
- Android declares `android.permission.INTERNET` because the Capacitor WebView shell includes it, but the bundled app does not configure `server.url` and the app source has no network API calls.
- iOS `Info.plist` does not declare camera, microphone, location, contacts, photo library, Bluetooth, speech recognition, or tracking usage descriptions.

## Repo Evidence

| Area | Evidence |
| --- | --- |
| Dependencies | `apps/starlit-apprentice/package.json` includes Capacitor and the local product core only; the pixel stage uses the browser Canvas API without a third-party game engine. |
| Remote code | `apps/starlit-apprentice/capacitor.config.ts` uses `webDir: "dist"` and has no `server.url`. |
| WebView CSP | `apps/starlit-apprentice/index.html` keeps scripts and runtime connections self-only and blocks frame/object/form surfaces. |
| Network APIs | `apps/starlit-apprentice/src` and `packages/product-core/src` contain no `fetch`, `XMLHttpRequest`, `sendBeacon`, `WebSocket`, `EventSource`, or `RTCPeerConnection` use. |
| Local storage | `apps/starlit-apprentice/src/storage.ts` stores run progress and ending collection in `localStorage`, and `clearAllStorage()` removes both local keys. |
| Analytics contract | `apps/starlit-apprentice/src/app.ts` emits only local `starlit:analytics` CustomEvent payloads and ships no analytics SDK or network transport. |
| Android permissions | `apps/starlit-apprentice/android/app/src/main/AndroidManifest.xml` contains only Capacitor's `INTERNET` permission and no sensitive permission. |
| iOS usage descriptions | `apps/starlit-apprentice/ios/App/App/Info.plist` contains no privacy usage description keys. |

## Google Play Data Safety Candidate

- Status: repo evidence prepared; Play Console submission remains manual.
- Candidate declaration: no user data collected.
- Candidate declaration: no user data shared.
- On-device data: local progress and ending collection only.
- Account deletion: not applicable because the app has no account system or server-held user data.
- privacy policy URL remains a manual console gate.
- Public policy page source: `public-pages/privacy-policy.html`, generated by `pnpm release:public-pages` and documented in `docs/public-release-pages.md`.

Google Play requires developers to complete the Data safety form and provide a privacy policy even when an app does not collect user data:
`https://support.google.com/googleplay/android-developer/answer/10787469?hl=en`

## App Store App Privacy Candidate

- Status: repo evidence prepared; App Store Connect submission remains manual.
- Candidate label: Data Not Collected.
- Tracking: no.
- Third-party partner collection: none in the MVP boundary.
- IDFA: no, matching `reviewDeclarations.advertisingIdentifier`.
- privacy policy URL remains a manual console gate.
- Public policy page source: `public-pages/privacy-policy.html`, generated by `pnpm release:public-pages` and documented in `docs/public-release-pages.md`.

Apple requires developers to identify data collected by the app and third-party partners:
`https://developer.apple.com/app-store/app-privacy-details/`

## Verification

Run:

```bash
pnpm check:privacy
pnpm check:analytics-contract
pnpm check:webview-security
pnpm release:public-pages
pnpm check:public-pages
```

The checkers fail if network APIs, remote WebView code paths, sensitive native permissions, disallowed tracking/analytics/ads dependencies, missing evidence text, or mismatched store privacy declaration fields are introduced.
