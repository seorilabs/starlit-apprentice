# docs — 실행 원장

이 디렉터리가 이 저장소의 **source of truth**다. Obsidian은 보조 지식베이스다.

| 폴더 | 역할 |
|---|---|
| `01-planning/` | 제품 범위, 출시 타깃 |
| `02-decisions/` | ADR. **되돌리기 어려운 결정은 전부 여기 있다** |
| `03-architecture/` | 계층 경계, 데이터 계약 |
| `04-work/` | 작업 실행 기록 |
| `05-markets/` | Google Play · App Store · AppsInToss · Firebase · 게임물 등급 |
| `06-release/` | 릴리스 체크리스트 |
| `07-qa/` | 테스트 전략, 분석 이벤트 계약, 수동 QA |
| `08-ops/` | 운영 런북 |
| `09-knowledge/` | 재사용 가능한 학습, third-party notices |
| `game-design/` | 상용 설계 팩 9종 (제품 브리프 ~ QA·론칭, 결정 로그) |

콘솔에서만 바뀐 값은 release-ready로 보지 않는다. 마켓 관련 값은 repo-local config 또는 `05-markets/`에 남긴다.
확정해야 하는데 아직 모르는 값은 `확정 필요`로 남기고 임의로 채우지 않는다.
