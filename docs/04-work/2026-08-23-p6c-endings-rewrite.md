# 엔딩 30종 재저작과 섀도잉 린트

- 날짜: 2026-08-23
- 단계: P6 콘텐츠 — 엔딩 재저작, 설계 불변식 8 구현
- 관련: [[2026-08-23-p4-core-port]] · [[../game-design/02-gdd]]

## 왜 필요했나

구 엔딩 데이터는 **14스탯**을 쓰는데 새 코어는 **9스탯**이다. 재저작하지 않으면 판정이 아예 성립하지 않는다. 이것이 30루트 재저작(4.3c 완료)을 막고 있던 블로커였다.

## 재저작

| band | 이름 | 개수 | 요건 성격 |
|---:|---|---:|---|
| 0 | 실패 | 3 | 낙제 / 빚 / 조용한 일상(폴백) |
| 1 | 일상 | 5 | 단일 스탯 45~50 |
| 2 | 전문 | 10 | 스탯 2개 55~68 + 플래그 |
| 3 | 희귀 | 8 | 스탯 3개 60~80 + **진로 선언** + 평판 |
| 4 | 전설 | 4 | 스탯 78~88 + **NPC 호감 80** + 진로 + 무낙제 + 평판 60 |

요건 103개, 한글 2,502자. **구 스탯 잔존 0.**

band 3 중 2종은 이든 관계의 두 종착점에 걸린다 — `eden-coauthor`(동맹)와 `solo-name`(경쟁). 중간(호감 30~60)은 어느 쪽에도 도달하지 않는다.

## 판정기 확장

요건 타입 3종을 추가했다.

| 타입 | 용도 | 특이도 가중 |
|---|---|---:|
| `affinity` | NPC 호감 (band 4) | `target / 8` |
| `condition` | 상태이상. `direction: absent` 로 "그 상태가 아니어야 한다" | 4.0 |
| `declared` | **진로 선언. band ≥ 3 의 하드 요건** | 6.0 |

`declared` 가 희귀·전설 엔딩을 **선언 없이 도달 불가능**하게 만든다. 구 구현의 `targetEndingCode` 는 판정이 읽지도 않았다.

legacy 등가성 179 조합은 그대로 통과한다 — 새 타입이 구 데이터 경로를 건드리지 않는다.

## 섀도잉 린트 (설계 불변식 8)

`tests/endings_lint_runner.gd`. **실제 판정 공식(`SaEndingJudgement.specificity`)을 그대로 호출한다.** Python 으로 재구현하면 린트와 런타임이 어긋날 수 있어서다.

검사 항목:
- 엔딩 30개, band 분포가 설계와 일치
- 코드 중복 금지
- **band ≥ 3 은 `declared` 요건 필수**
- 폴백은 요건이 없어야 함
- **A 의 요건이 B 의 상위집합인데 특이도가 B 이하면 실패** (A 는 영원히 도달 불가능)
- 요건 집합이 완전히 동일한 쌍 금지
- **특이도가 band 와 함께 단조 증가**

실측:

```
band 별 최대 특이도: { 0: 4.0, 1: 7.0, 2: 24.3, 3: 40.1, 4: 54.3 }
ENDINGS LINT PASS (엔딩 30, 요건 103)
```

주입 검증:

| 주입 | 결과 |
|---|---|
| 상위집합인데 특이도 낮은 엔딩 추가 | exit=1 |
| band 3 의 `declared` 요건 제거 | exit=1 |
| 두 엔딩의 요건 집합을 동일하게 | exit=1 |
| 복구 후 | exit=0 |

구 구현에서 `priority: 30` 세 개가 26종을 가리던 문제가 이제 **콘텐츠 PR 단계에서 막힌다.**
