## 생성

30종, 실패 0건. 승인된 앵커를 스타일 레퍼런스로 상속했다.

**수업은 계열 3티어가 아이콘 하나를 공유한다.** 티어는 UI 배지로 표시하므로 아이콘 18개 대신 6개면 된다 — 예산과 저작 비용을 함께 줄인다.

## QA 가 잡은 3건

콘택트시트를 어두운 배경·밝은 배경 양쪽으로 검수해 재생성했다.

| 아이콘 | 문제 | 수정 |
|---|---|---|
| `icon_workshop` | **망원경을 그려 `icon_starlore` 와 시각적으로 충돌** | 모루 + 망치 + 풀무 |
| `icon_watch` | 등불과 원반이 뭉개져 무엇인지 안 읽힘 | 초소 등불 + 방패 |
| `icon_drill` | 훈련이 아니라 두루마리로 읽힘 | 훈련 기둥 + 봉 |

## 액션 매핑과 린트

`data/actions.json` 의 38개 액션 전부에 `icon` 필드를 넣고, **아이콘 파일이 실재하는지 린트가 검사**한다. 없는 아이콘을 참조하면 `exit=1` (주입 검증 확인). UI 가 빈 칸을 그리는 상황을 데이터 차원에서 막는다.

사용 아이콘 26종 / 액션 38개.

## `scripts/finalize_art.sh`

WebP 변환과 import Lossy 고정을 두 번 임시로 하다가 스크립트로 고정했다. ADR-0008 의 두 단계를 한 명령으로 묶는다.

동작 검증:
- `.import` 가 아직 없으면 **exit 2 로 멈추고 `godot --import` 를 먼저 돌리라고 안내**한다. 실제로 30종 생성 직후 이 경로를 탔다.
- import 이후 재실행하면 "Lossy 고정 0개" 가 나온다. **신규 자산이 `project.godot` 의 `importer_defaults` 를 자동으로 따랐다는 뜻**이다. ADR-0008 의 4번 조치가 실제로 동작함을 확인했다.
